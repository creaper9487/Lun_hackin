# 實驗預約

在這裡排想做的主題。排程跑的時候會先看這裡：取 **待做** 中第一個到期（日期是今天或更早、或沒寫日期）的項目。沒有到期項目時，它才會自己上網找點子。

格式（日期、連結、備註都可省略）：

```
- [ ] 2026-10-20 · 主題 · https://參考網頁 · 備註：想要的方向、限制
```

- 日期是「最早可以做的日子」，不是截止日。
- 只放網址也可以，例如 `- [ ] https://example.com/some-demo · 研究它的捲動效果`。
- 可以直接在 GitHub 網頁上編輯並 commit，下次執行時會自動 pull。本機改了但沒 commit 也可以，它會一起 commit。
